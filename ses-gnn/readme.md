# SES-GNN: предсказание сайтов связывания

- `preprocess.py` — строит SES поверхность из PDB
- `build_graphs.py` — строит графы (рекомендуемые параметры: R=3Å, MAX_NEIGHBORS=48, SIGMA=3.0)
- `train_clean.py` — обучает GNN (один GPU)
- `train_clean_ddp.py` — обучает GNN (несколько GPU, DDP)
- `evaluate.py` — оценка модели на тестовых данных с поддержкой фиксированного порога и проверки пересечений

## Установка

```bash
conda create -n ses-gnn python=3.10
conda activate ses-gnn
pip install -r requirements.txt
```

## Запуск

```bash
# 1. SES поверхность
python preprocess.py --dataset training_ppi.txt --pdb_dir ./pdb_files --out_dir ./data/raw

# 2. Графы (рекомендуемые параметры)
python build_graphs.py --raw_dir ./data/raw --out_dir ./data/graphs --r_cutoff 3.0 --max_neighbors 48 --sigma 3.0

# 3. Обучение на нескольких GPU (DDP) с рекомендуемыми параметрами
python train_clean_ddp.py \
    --data_dir ./data/graphs \
    --n_files 5000 \
    --n_val 50 \
    --layers 6 \
    --hidden 32 \
    --heads 4 \
    --lr 1e-3 \
    --hard_ratio 2.0 \
    --ckpt_f1 best_f1.pt \
    --ckpt_roc best_roc.pt \
    --ckpt_pr best_pr.pt \
    --log_dir ./logs

# 4. Оценка модели на тесте (фиксированный порог, проверка пересечений)
python evaluate.py \
    --model best_roc.pt \
    --data_dir ./data/graphs \
    --output_dir ./evaluation_results \
    --n_files 412 \
    --threshold 0.272 \
    --heads 4

# 5. Визуализация
python viz.py --model best_model.pt --name 3P0C_D --threshold 0.4
```

## Параметры train_clean_ddp.py

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `--data_dir` | `./data/graphs` | Папка с графами |
| `--n_files` | `3000` | Число файлов для обучения |
| `--n_val` | `50` | Число файлов для валидации |
| `--threshold` | `4.0` | Порог интерфейса (Å) |
| `--layers` | `6` | Слоёв TransformerConv |
| `--hidden` | `32` | Размер скрытого слоя |
| `--heads` | `4` | Число голов внимания |
| `--lr` | `1e-3` | Learning rate |
| `--epochs` | `300` | Эпох |
| `--hard_ratio` | `2.0` | Hard negative mining ratio |
| `--ckpt_f1` | `best_f1.pt` | Чекпоинт по F1 |
| `--ckpt_roc` | `best_roc.pt` | Чекпоинт по ROC-AUC |
| `--ckpt_pr` | `best_pr.pt` | Чекпоинт по PR-AUC |
| `--resume` | `None` | Путь к чекпоинту для продолжения |
| `--checkpoint` | `True` | Gradient checkpointing (экономия памяти) |
| `--log_dir` | `./logs` | Папка для логов (CSV, TensorBoard, списки файлов) |

- Мы **превзошли dMaSIF по F1, Recall и PR‑AUC**.

**Наши преимущества:**
- Инференс быстрее (оценочно в 5 раз)
- Памяти меньше (оценочно в 7 раз)

- Сквозной пайплайн от PDB до предсказания

## 🛠️ Технические детали

### Оценка модели (evaluate.py)

- **Автоопределение архитектуры:** `evaluate.py` автоматически определяет `hidden`, `layers`, `heads` из чекпоинта (или их можно задать вручную).
- **Фиксированный порог:** позволяет указать `--threshold` для воспроизводимых результатов.
- **Проверка пересечений:** если в текущей директории есть `train_files.txt` (сохраняется при обучении), evaluate автоматически проверяет, что тестовые файлы не пересекаются с обучающими.
- **Тестовый сплит:** по умолчанию используется `--shuffle_seed 42` для согласованности с обучением.

### Воспроизводимость

При обучении `train_clean_ddp.py` сохраняет в `--log_dir`:
- `train_files.txt` — список файлов, использованных для обучения
- `val_files.txt` — список файлов для валидации (пока не сделано, но логично добавить)
- Полный CSV‑лог метрик по эпохам

Это гарантирует, что тестовый набор можно строго определить как все файлы, не попавшие в train+val, и исключить data leakage.
