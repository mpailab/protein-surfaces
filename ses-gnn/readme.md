# SES-GNN: предсказание сайтов связывания

Три скрипта:
- `preprocess.py` — строит SES поверхность из PDB
- `build_graphs.py` — строит графы
- `train.py` — обучает GNN

## Установка

```bash
conda create -n ses-gnn python=3.10
conda activate ses-gnn
pip install -r requirements.txt
```

## Запуск

```bash
# 1. SES поверхность
python preprocess.py --dataset training_ppi.txt --pdb_dir ./pdb_files --out_dir ./data/raw

# 2. Графы
python build_graphs.py --raw_dir ./data/raw --out_dir ./data/graphs --r_cutoff 3.0

# 3. Обучение
python train.py --data_dir ./data/graphs --n_files 500 --threshold 4.0 --layers 6 --hidden 64 --lr 1e-3

# 4. Визуализация
python viz.py --model best_model.pt --name 3P0C_D --threshold 0.4
```

## Параметры train.py

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `--data_dir` | `./data/graphs` | Папка с графами |
| `--n_files` | `2` | Число файлов для обучения |
| `--threshold` | `4.0` | Порог интерфейса (Å) |
| `--layers` | `6` | Слоёв TransformerConv |
| `--hidden` | `64` | Размер скрытого слоя |
| `--lr` | `1e-3` | Learning rate |
| `--epochs` | `300` | Эпох |
| `--ckpt` | `best_model.pt` | Имя чекпоинта |

## 🔬 План экспериментов (что дальше)

### Эксперимент 1: Мультимасштабные графы (приоритет 1)

**Гипотеза:** рёбра на 2Å, 4Å и 8Å дадут и локальную геометрию, и глобальный контекст.

**Как проверить:**
```python
# В build_graphs.py или прямо в train.py
e1 = radius_graph(pos, r=2.0, max_num_neighbors=24)
e2 = radius_graph(pos, r=4.0, max_num_neighbors=32)
e3 = radius_graph(pos, r=8.0, max_num_neighbors=48)
edge_index = torch.cat([e1, e2, e3], dim=1)
```

**Ожидаемый прирост:** ROC-AUC +0.05-0.08

---

### Эксперимент 2: Глобальный контекст через пулинг (приоритет 2)

**Гипотеза:** каждая точка должна знать, где она находится на всей поверхности.

**Как проверить:**
```python
# В модели, после свёрток
x_global = torch.max(x, dim=0)[0]  # глобальный максимум
x = x + x_global.unsqueeze(0)      # добавить к каждой точке
```

**Ожидаемый прирост:** ROC-AUC +0.03-0.05

---

### Эксперимент 3: Больше данных (приоритет 3)

**Гипотеза:** 500 → 1000 → 1800 файлов дадут прирост.

**Как проверить:**
```bash
python train.py --n_files 1000
python train.py --n_files 1800
```

**Ожидаемый прирост:** ROC-AUC +0.03-0.05

---

### Эксперимент 4: Добавить признаки из dMaSIF (приоритет 4)

**Гипотеза:** электростатика, гидрофобность, кривизна помогут.

**Что нужно добавить в preprocess.py:**
- Poisson-Boltzmann электростатика (APBS)
- Hydropathy (Kyte-Doolittle)
- Gaussian/mean curvature

**Ожидаемый прирост:** ROC-AUC +0.04-0.07

### Эксперимент 5: Ансамбль моделей (приоритет 5)

**Гипотеза:** усреднение 3-5 моделей снизит дисперсию.

python train.py --n_files 500 --ckpt model3.pt --seed 777
# Усреднить логиты

**Ожидаемый прирост:** F1 +0.02-0.03

---

### Эксперимент 6: Увеличить модель (приоритет 6)

**Гипотеза:** 8-10 слоёв, hidden=128-256 могут дать прирост (если памяти хватит).

```bash

```

**Ожидаемый прирост:** ROC-AUC +0.02-0.04
